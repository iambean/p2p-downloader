# Third-party components

The macOS application embeds Sparkle (https://sparkle-project.org/), copyright
the Sparkle Project and contributors. Its license is included as
`SPARKLE-LICENSE.txt` inside the application bundle. Sparkle provides signed
software-update delivery and installation.

Python 3, aMule and aria2 are external runtime dependencies. They are not bundled
in the application or its release archives. Their respective licenses and
source code are available from their upstream projects:

- Python: https://www.python.org/psf/license/
- aMule: https://github.com/amule-org/amule
- aria2: https://github.com/aria2/aria2

The application icon is drawn by this project's AppKit build script.
